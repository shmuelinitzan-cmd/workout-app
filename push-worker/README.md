# שרת התראות לסיום מנוחה

שרת זעיר ב-Cloudflare (חינם) ששולח לאייפון התראת Push בסוף המנוחה, גם כשהמסך כבוי ובלי לעצור את Spotify.

## הגדרה חד-פעמית

דרישות: Node.js מותקן במחשב, וחשבון Cloudflare חינמי.

```
cd push-worker
npx wrangler login
node setup.mjs
```

`setup.mjs` מפרסם את ה-Worker, שומר את המפתח הפרטי כ-secret ב-Cloudflare (הוא לא נכנס ל-git),
וכותב את כתובת ה-Worker ואת המפתח הציבורי לתוך `index.html`. אחרי זה:

1. עושים commit ו-push ל-`index.html` ול-`sw.js` (וגם לתיקיית `push-worker`).
2. פותחים את האפליקציה בטלפון, מסך הבית ← גיבוי ← "התראה במסך נעול" ← **פעילה**, ומאשרים את ההרשאה.
3. לוחצים "נסה", נועלים את המסך, ומחכים 8 שניות.

אם `setup.mjs` נכשל בפרסום הראשון (למשל כי wrangler רוצה לשאול על שם ה-workers.dev), מריצים פעם אחת
`npx wrangler deploy` ידנית ואז שוב `node setup.mjs`.

## דרישות בטלפון

- iOS 16.4 ומעלה.
- האפליקציה חייבת להיות מותקנת במסך הבית (לא נפתחת מ-Safari).
- ההתראות חייבות להיות מאושרות: הגדרות ← התראות ← אימונים.

## איך זה עובד

- בתחילת מנוחה האפליקציה שולחת ל-Worker "תשלח התראה בעוד N שניות". הטקסט (שם התרגיל ומספר הסט) נשמר בטלפון.
- השהיה, דילוג, יציאה מהאימון או חזרה למסך בשניות האחרונות מבטלים את ההתראה, כדי שלא יהיה צליל כפול.
- במצב מוזיקה "ממשיכה" ההתראה היא הדרך היחידה לשמוע על סוף המנוחה כשהמסך כבוי.
  במצב "נעצרת" הצליל מהרצועה כבר עובד, וההתראה משמשת רק כגיבוי אם הרצועה לא הצליחה לנגן.
- הצליל הוא צליל ההתראה הרגיל של האייפון. אי אפשר להשמיע `timerend.mp3` דרך התראת Push.

## תחזוקה

- שינוי ב-`worker.js`: `npx wrangler deploy` מתוך התיקייה הזו.
- מפתחות: אל תריצו מחדש עם מפתח חדש. החלפת המפתח הציבורי ב-`index.html` מבטלת את ההרשמה בטלפון, ואז צריך לכבות ולהפעיל שוב בהגדרות.
